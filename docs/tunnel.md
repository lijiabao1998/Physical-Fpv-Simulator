# 虛擬風洞（`fpvsim tunnel`、`fpvsim fit-tunnel`）

真實研發會把整機或單顆動力組放進風洞，用六分量天平量測力與力矩。虛擬風洞做同樣的事，對象是飛行模擬使用的同一個模型（`dynamics.py` 的整機、`rotor_ff.py` 的槳），所以報告裡的數字就是模擬飛行時的空氣動力。三個用途：

1. **看懂模型**：前飛要多大的傾角、多少功率，機身阻力與槳盤阻力各占多少，最省電與航程最遠的速度。
2. **設計量測**：哪些參數決定這些結果（敏感度），實測時要量哪些風速與攻角。
3. **辨識參數**：把真實風洞的天平數據套回模型，辨識阻力面積、阻力中心與槳的揮舞比例，附上不確定度，直接貼回零件檔。

```bash
fpvsim tunnel     data/builds/ref-5in-6s-freestyle.toml                     # 報告：out/tunnel-<build>/
fpvsim tunnel     data/builds/ref-5in-6s-freestyle.toml --synthetic bal.csv # 另外輸出含雜訊的合成天平數據
fpvsim fit-tunnel bal.csv --build data/builds/ref-5in-6s-freestyle.toml    # 辨識報告與 TOML 片段
```

選項：`--samples`（配平曲線的蒙地卡羅樣本數，預設 200，0 為不做）、`--soc`（天平上的電池電量，預設滿電）、`--exact`（合成數據不加雜訊）、`--synthetic-only`。

## 試驗段與天平

- 自由流速度 V、攻角 α（機頭向下為正，即前飛時的前傾）、側滑角 β（風從右方來為正），均勻流。
- 天平量測點在重心：力為機體軸（前、右、下），力矩為對重心的機體軸力矩；升力、阻力、側力為同一個力在風軸的分量。
- 槳的狀態：
  - **拆槳**：只有機身與零件的阻力（量機身阻力的標準做法）。
  - **停轉**：槳固定不轉，由斜向氣流模型計算（失速後的平板模型）。
  - **固定轉速**：解出每顆馬達維持該轉速所需的油門。
  - **固定油門**：解出每顆馬達的平衡轉速。
- 電池是機體自己的模型，預設滿電、靜置、起飛溫度。
- 真實風洞的洞壁修正、阻塞修正與支架（tare）修正屬於量測端，應在匯入數據前完成；虛擬風洞是自由流，沒有這些效應。

實作上，天平讀值就是 `QuadModel.derivative` 在機體角速度為零、遠離地面時的結果：力 = m·a − m·g，力矩 = I·ω̇（角速度為零，沒有陀螺與尤拉項）。

## 試驗項目

1. **機身阻力極曲線**：拆槳與停轉，風速 5–30 m/s、攻角 −10° 到 90°：阻力面積 D/(½ρV²)、升力、俯仰力矩。
2. **動力組在斜向氣流中**：單顆槳固定在懸停轉速，風速 0–30 m/s、槳盤攻角 0°（水平氣流）到 90°（軸向爬升）：推力、H 力、扭矩。
3. **配平曲線**：每個速度求水平定速飛行的傾角、總油門與前後油門差，使淨力與俯仰力矩為零，馬達在平衡轉速（7 個未知數、7 條方程式，一次求解，各速度以前一點為初值）。滾轉與偏航力矩只列殘差。阻力分成機身（各軸阻力面積）與槳（面內力）沿飛行路徑的分量。
4. **功率曲線**：電池輸出功率對速度；最低功率的速度（續航最久）與最低「功率 ÷ 速度」的速度（航程最遠），拋物線內插；任何一顆馬達需要超過全油門時即為最高平飛速度（二分法求到 0.001 m/s 以內）。另外以定速平飛從滿電開始，每 5 秒依電池狀態重新配平，算出續航與航程（結束條件與懸停續航相同：保留電量、負載下單芯電壓、電池溫度，或電壓不足以維持該速度）。

不確定度：與設計報告相同的參數分布，每組蒙地卡羅樣本重新計算整條配平曲線；另做單一參數 ±1σ 的敏感度，對應到量測方法。

## 驗證

`tests/test_tunnel.py`：

- 拆槳時 α = 0° 的阻力等於 ½ρV² × x 向阻力面積總和，α = 90° 等於 z 向；阻力面積與速度無關；俯仰力矩等於各阻力點的 r × F。
- 速度 0 的配平等於靜態懸停工作點（油門與功率差 < 0.2%），定速續航在速度 0 時等於懸停續航（< 0.5%）。
- 傾角隨速度增加；最低功率速度 < 航程最遠速度 < 最高速度；最高速度時有馬達在全油門。
- 合成數據不加雜訊時，辨識回原值；加上天平雜訊時，估計值在 3 個標準誤差內。

另一個交叉檢查：6DOF 飛行模擬的 `forward` 腳本在約 10.05 m/s 時的前飛傾角約 13.8°，配平曲線在 10 m/s 為 13.6°。

## 天平數據格式

CSV，第一列為 `名稱 [單位]`（與推力台、HPPC 相同的慣例），每列一筆讀值：

| 欄位 | 說明 |
|---|---|
| `props [1]` | 0 = 拆槳，1 = 停轉，2 = 固定轉速 |
| `speed [m/s]`、`alpha [deg]`、`beta [deg]` | 自由流與姿態 |
| `rpm [rpm]` | 槳的轉速（固定轉速時） |
| `rho [kg/m^3]` | 試驗時的空氣密度 |
| `fx [N]`、`fy [N]`、`fz [N]` | 機體軸的力（前、右、下） |
| `mx [N*m]`、`my [N*m]`、`mz [N*m]` | 對重心的機體軸力矩 |

合成數據的雜訊：力 0.01 N + 0.5% 讀值、力矩 0.0005 N·m + 0.5% 讀值（1σ，常態）；試驗矩陣為拆槳的 5 個風速 × 8 個攻角 + 3 個側滑角，以及懸停轉速與 1.3 倍懸停轉速、5 個風速的水平氣流。

## 辨識（`fit-tunnel`）

模型與飛行模擬相同（k = ½ρ|v|，機體軸空速 (u, v, w) 由 V、α、β 求得）：

- 拆槳：F_x = −k·u·S_x、F_y = −k·v·S_y、F_z = −k·w·S_z；對重心 M_y = −k·u·(S_x z_x) + k·w·(S_z x_z)、M_x = −k·w·(S_z y_z) + k·v·(S_y z_y)。S 為整機的阻力面積總和（機架加上有自己阻力的零件），x_z、y_z、z_x 為阻力中心相對重心的位置。每條式子對未知數是線性的。
- 固定轉速、水平氣流：x 向力另外加上各槳的面內力，在斜向氣流模型中對揮舞比例 f 是線性的：H = H_剛性 + f·(H_自由 − H_剛性)。與拆槳數據一起擬合，共用 S_x。
- 最小平方法，HC3 穩健標準誤差（`sysid.py`）；位置為兩個估計值的比，以一階誤差傳遞。
- 推力、側力與轉動時的力矩不用於辨識，以免推力模型的誤差混入阻力。

寫回零件檔時，機架的阻力面積 = 辨識的總和 − 各零件自己的阻力面積（取標稱值），阻力中心換算成機架檔座標（安裝原點）。揮舞比例超出 0 到 1 表示剛性與自由揮舞兩個極限都解釋不了量到的 H 力，模型本身需要檢討，報告會標出，不要直接寫回。

合成數據來自同一個模型，只能驗證辨識流程能否找回已知值，不能確認模型是否符合現實；確認需要真實風洞數據。

## 限制

- 機身阻力為三軸獨立的阻力面積，沒有機身升力與側力的交叉項；攻角之間的阻力面積因此是 cos²α、sin²α 加權，真實機身的極曲線未必如此。
- 槳與機身、槳與槳之間的干擾只以固定的推力比例表示。
- 配平是靜態平衡，不含飛控動態；最高速度以天平上的電池狀態（預設滿電）計算。
