# 物理模型

每個模型列出：方程、假設、適用範圍、可信度，以及如何用實測數據取代估計值。

## 大氣（`atmosphere.py`）

ISA 標準大氣，對流層（−500 至 11000 m）。氣壓由氣壓高度計算，密度使用實際氣溫：

    p = p₀ (1 − L h / T₀)^(g₀ / (R L)),   ρ = p / (R T)

- 忽略濕度：在一般飛行條件下，對密度的影響小於 1%。
- 重力使用標準重力 g₀ = 9.80665 m/s²，忽略緯度與高度變化（< 0.3%）。
- 參考：ISO 2533:1975。
- 可信度：高。

## 質量性質（`mass.py`）

每個零件是均勻密度的幾何體（點、箱體、實心或空心圓柱），在機體座標中有位置與姿態：

    M = Σ mᵢ,   r_cg = Σ mᵢ rᵢ / M
    I_cg = Σ [ Rᵢ Iᵢ Rᵢᵀ + mᵢ (|dᵢ|² E − dᵢ dᵢᵀ) ],   dᵢ = rᵢ − r_cg

- 槳以點質量表示：它對機體慣性的自身貢獻小於 0.5%。槳與轉子的自轉慣量另外記錄，供飛行動力學使用。
- 分散在全機的小零件（螺絲、線材）以單點近似，會略微低估慣性。
- 可信度：高，前提是零件質量與位置正確。
- 實測方法：秤重；重心可用懸吊法量測，慣性可用雙線擺（bifilar pendulum）量測。

## 電池（`battery.py`）

一階 Thevenin 等效電路加上集總熱模型：

    V = OCV(SoC) − v_rc − I·R0(T)
    dv_rc/dt = (I·R1(T) − v_rc) / τ1
    dSoC/dt = −I / Q
    C_th dT/dt = I²·R0(T) + v_rc²/R1(T) − hA(v)·(T − T_環境)

- **內阻隨溫度：** Arrhenius 關係 R(T) = R(T_ref)·exp[(Eₐ/R)(1/T − 1/T_ref)]。r0_cell、r1_cell 是 T_ref（25 °C）的值；Eₐ = 20 kJ/mol 約讓 0 °C 的內阻變成 2 倍。
- **熱模型：** 熱容量 C_th = 比熱 × 電池質量。散熱 hA 在懸停時是 `ha_hover`（只有槳的入流），隨空速依 √v 增加（層流強制對流），在 `ha_speed` 時等於 `ha_ref`。熱源是歐姆損耗加上極化電阻的損耗；可逆的熵熱在高放電倍率下相對很小，忽略。
- **老化：** 循環次數 N 讓容量乘上 (1 − capacity_fade·N/100)、內阻乘上 (1 + resistance_growth·N/100)。這是一階線性近似；真實電池接近壽命終點時衰退會加速。
- **起飛狀態：** 滿電、極化電壓為 0，溫度是規格的 `battery_temperature`（預設等於氣溫）。
- 時間步進中，RC 對定電流使用精確指數解；熱節點在熱源凍結於一步內時也是精確解。
- 不模擬：低溫下電化學反應變慢造成的可用容量下降（只計入內阻變大）、放電倍率對容量的影響、OCV 的溫度係數、電芯之間的不平衡。
- OCV 曲線是鈷酸鋰系 LiPo 的典型值。
- 可信度：中（電路）；熱參數與老化速率為低（估計值）。
- 實測方法：容量用定電流放電測試；R0、R1、τ1 用脈衝放電測試（HPPC），由瞬間壓降與恢復曲線擬合（`fpvsim fit-battery`）；OCV 用 C/20 低倍率放電或間歇靜置測試；Eₐ 由兩個溫度下的 HPPC 反推；熱容量與散熱由貼熱電偶的放電與降溫曲線辨識；老化靠定期記錄容量與內阻。

**全油門可持續時間**（`performance.full_throttle_burst`）：從滿電、起飛溫度開始靜止全油門，直到電池溫度到上限、負載下單芯電壓低於瞬間下限（規格的 `burst_cell_voltage`），或電量到保留值。它取代以標示 C 數判斷的電流上限。

## 馬達與 ESC（`motor.py`）

在 PWM 週期與電氣週期上取平均的直流馬達模型：

    V_m = duty · V_bus,        I_bus = duty · I_m        （ESC 視為理想降壓轉換器）
    I_m = (V_m − Ke·ω) / (Rm + R_esc)
    τ   = Kt · (I_m − I₀(ω)),  Kt = Ke = 1/Kv（SI）
    I₀(ω) = I₀_ref · [(1 − f) + f · ω / ω_ref]

- 忽略繞組電感：電氣時間常數約數十微秒，遠小於機械時間常數（數十毫秒）。
- 空載損耗分成定值部分（軸承摩擦、磁滯）與正比於轉速的部分（渦流、黏滯）。
- 槳負載為 Q = kQ·ω² 時，穩態轉速有閉式解（一元二次方程的正根）。
- ESC 損耗以導通電阻 R_esc 與固定靜態功率表示，忽略開關損耗。
- 不模擬：繞組溫升造成的電阻上升（銅約 +0.39%/°C）、磁鐵溫度、相位超前。
- 可信度：中。
- 實測方法：Rm 用四線法量測；Kv 與空載損耗用無槳空載測試，至少兩個電壓（`sysid.fit_motor_no_load`）；負載測試可以交叉檢查 Ke 與迴路電阻（`sysid.fit_motor_loaded`）。

## 槳（`prop.py`、`bemt.py`）

無因次係數，n 的單位是每秒轉數，J = V/(nD) 是前進比：

    T = Ct(J)·ρ·n²·D⁴,   P = Cp(J)·ρ·n³·D⁵,   Q = P / (2πn)

係數來源依優先順序：

1. **實測**：零件檔中的 `[coefficients]` 表，可由推力台數據以 `fpvsim fit-prop` 辨識。
2. **BEMT 估計**：由槳葉幾何（弦長分布、螺距、翼型極曲線）以葉素動量理論計算。每個環帶求解誘導速度 v，使葉素推力等於動量推力，並加入 Prandtl 葉尖損失：

        φ = atan((V + v) / (Ωr)),   α = θ(r) − φ
        dT_BE = B · ½ρW²c (Cl cos φ − Cd sin φ) dr
        dT_M  = 4πr ρ (V + v) v F dr

   根在 v = 0 與該截面零升力的入流之間，用 Brent 法求解，保證收斂。

假設與限制：

- 只處理軸向流（V ≥ 0）。下降時動量理論不成立（渦環狀態），程式會拒絕計算。
- 忽略旋流（切向誘導），對螺旋槳通常是 1–3% 的影響。
- 整片槳葉使用同一個翼型極曲線，沒有雷諾數或馬赫數相依性。失速後：升力先停在 cl_max／cl_min，攻角絕對值在 20° 到 40° 之間以餘弦權重過渡到平板（cl = C_N sin α cos α、cd = cd_min + C_N sin²α，C_N = 2.0，Hoerner 1965），逆流也用平板；沒有計入旋轉造成的失速延遲。
- 以本專案的估計葉片（等螺距 4.3 吋）而言，靜止時整片葉片的攻角都在失速上限以上（r/R = 0.75 處約 11°），所以靜推力主要由 cl_max 與弦長決定，螺距再加大反而略降。這依賴翼型的失速模型，是推力台數據最能修正的地方。
- 因此 BEMT 已知會**高估小槳的效率**。模型不確定度以 Ct ±10%、Cp ±15%（1σ）表示。
- 報告會列出全油門的槳尖馬赫數；超過約 0.7 時已超出模型適用範圍。
- 可信度：中低，尚未確認。是目前續航與推重比不確定度的最大來源。
- 參考：Glauert, *Airplane Propellers* (1935)；Leishman, *Principles of Helicopter Aerodynamics*, 2nd ed. (2006), ch. 3。

## 槳在斜向氣流中（`rotor_ff.py`）

前飛、爬升、下降（含渦環狀態）、收油後的低轉速高速，以及停轉的槳，都用同一個葉素模型。輸入與軸向 BEMT 相同（槳葉幾何與翼型）；有實測係數表時，幾何仍用來計算斜向氣流的變化比例。

**無因次化。** 旋翼通常以槳尖速度 ΩR 無因次化，但收油後高速俯衝或爬升滑行時 ΩR 遠小於空速，停轉時則是零。所以表格以總參考速度

    V_ref = √((ΩR)² + V_e² + V_c²)

為準，座標 μ = V_e / V_ref（0 到 1，槳轂的水平空速）、λ = V_c / V_ref（−1 到 1，沿推力軸的爬升速度），係數以 q = ρ A V_ref² 無因次化（力矩再乘 R）。一般旋翼定義的前進比與入流比是 μ/s、λ/s，s = ΩR/V_ref = √(1 − μ² − λ²)；懸停與一般飛行時 s 接近 1，兩者幾乎相同。表格點距 0.02，共 51 × 101 點，每顆槳算一次（約 15 秒）後快取在 `~/.cache/fpvsim`（`FPVSIM_CACHE` 可改）。

**葉素。** 沿半徑 24 段、方位角 36 段積分（ψ 由前進方向量起，逆時針旋轉的槳）：

    U_T = Ωr − V_e sin ψ,   U_R = V_e cos ψ,   U_P = V_c + v_i(r, ψ)
    α = θ(r) − atan2(U_P, U_T)
    升力 ½ρ(U_T² + U_P²) c Cl(α) F，阻力 ½ρ c Cd |W| W（沿完整相對速度）

極曲線與 BEMT 相同（含失速後的平板與逆流），F 為 Prandtl 葉尖損失。得到推力 C_T、面內阻力 C_H（真正的槳盤阻力）、側力 C_Y、扭矩 C_Q，以及槳轂的滾轉力矩 C_Mx（前進側升力較大）與俯仰力矩 C_My。順時針的槳是鏡像：C_Y 與 C_Mx 反號，其餘不變。

**誘導速度。** 均勻部分 v₀ 加上 Drees 線性分布 v_i = v₀(1 − k_x (r/R) cos ψ)（槳盤後方入流較大）。v₀：

- 爬升、懸停與前飛用 Glauert 動量理論：T = 2ρA v₀ √(V_e² + (V_c + v₀)²)。
- 軸向下降時，V_c/v_h 在 0 到 −2 之間動量理論沒有合理解（渦環狀態），改用 Leishman (2006) 第 2 章整理的經驗曲線 v_i/v_h = (1.15 − 1.125x − 1.372x² − 1.718x³ − 0.655x⁴)/1.15，x = V_c/v_h；多項式在 x = −2 為 1.0226，與動量理論差 2%，以一個在懸停為零的線性修正補上，讓曲線連續（迭代求解需要）。修正後理想自轉點在 V_c = −1.73 v_h（文獻約 −1.71）。x < −2（風車煞車狀態）回到動量理論。
- 有水平速度時尾流被吹離槳盤：水平速度 V_e/v_h 小於 `vrs_extent(x)`（最多 0.7）時完全用經驗值，到兩倍時完全回到 Glauert，中間以餘弦權重過渡。這個範圍是依 Glauert 方程有三個根（沒有連續解）的區域定的，數值檢查過完全包含該區域（最大約 V_e/v_h = 0.62，在 x ≈ −1.8）。
- 葉片沒有正推力時（風車狀態、停轉）不計誘導速度，只用葉素。

v_h = √(T/(2ρA)) 隨推力變化，所以 v₀ 與葉片負載以阻尼固定點迭代到收斂（|v₀ − 目標| < 2×10⁻⁵ V_ref，表格每一點都必須收斂）。

**葉片揮舞。** 葉素負載是剛性葉片的結果：前進側多出的升力全部變成槳轂力矩。完全自由揮舞（鉸接）的旋翼則會讓槳盤後傾經典的縱向揮舞角 a1 = 2μ(4θ₇₅/3 − λ)/(1 − μ²/2)（Johnson 1980；Leishman 2006 第 4 章，μ、λ 為旋翼定義），把部分推力轉成槳盤阻力 C_Hf = C_T·a1，並釋放槳轂力矩。經典解只在 μ < 0.5 成立，超過時（以及 |λ| > 0.5）a1 停在邊界值；轉速趨近零時揮舞需要的離心剛性消失，a1 在 ΩR < V_ref/2 時線性淡出。塑膠槳介於兩者之間，以 `prop.flap_fraction`（f，0 = 剛性，1 = 自由揮舞）混合：

    C_H,eff = C_H + f·C_Hf,   C_Mx,eff = (1 − f)·C_Mx,   C_My,eff = (1 − f)·C_My

橫向揮舞造成的側力在左右旋成對時互相抵消，沒有計入。f 沒有數據，取 0 到 1 的均勻分布（標稱 0.5），應由風洞量測槳在斜向氣流中的 H 力辨識。

**錨定在軸向數據。** 斜向氣流模型提供相對於軸向的變化；軸向本身仍以實測或 BEMT 的 Ct(J)、Cp(J)（含 `ct_scale`、`cp_scale`）為準。μ = 0 時 λ 對應 J = πλ/√(1 − λ²)，C_T = Ct·(4/π³)(1 − λ²)、C_Q = Cp·(4/π⁴)(1 − λ²)。在旋翼入流比 0 到 0.2（且推力仍大於靜推力 20%）的範圍內逐點求倍數 k_T(λ)、k_Q(λ)，範圍外維持端點值；所有力與力矩乘 k_T，扭矩乘 k_Q。參考槳的 k_T ≈ 1.04–1.07、k_Q ≈ 1.08–1.13（均勻入流的前飛模型在懸停比逐環帶求解的 BEMT 少約 7% 推力）。所以懸停與軸向爬升的結果和原本完全相同。

**結果（參考槳，標稱值）。**

| 項目 | 數值 |
|---|---|
| 定速平飛配平傾角（f = 0 / 0.5 / 1） | 10 m/s：9.8° / 13.6° / 16.8°；20 m/s：30° / 36° / 40°；30 m/s：60° / 62° / 64° |
| 配平功率（f = 0.5） | 懸停 82 W，最低約 80 W（5 m/s），20 m/s 153 W，30 m/s 484 W |
| 停轉槳的水平阻力 | 約 9 cm² 阻力面積（每顆） |
| 收油後以 40 m/s 爬升滑行（怠速約 2300 rpm） | 每顆槳約 −2 N（風車狀態的煞車力，與機身阻力同數量級） |

以前的動量理論 × 0.5 在 10 m/s（懸停轉速）給 2.1 N 槳盤阻力，新模型為 0.6 / 1.0 / 1.4 N（f = 0 / 0.5 / 1），約為一半：動量理論假設穿過槳盤的水平動量全部被轉向，確實是上限。新模型的阻力隨速度與轉速變化、包含停轉與風車狀態，而校正倍數換成有物理意義、可以量測的揮舞比例。槳轂俯仰力矩 C_My 很小，因為估計葉片在懸停時已在失速上限，前後入流差不太改變升力；這個結論依賴失速模型，需要風洞確認。

**驗證**（`tests/test_rotor_ff.py`）：誘導速度曲線在 x = 0 與 −2 連續、平飛時等於 Glauert 解析解、整個 (x, y) 平面沒有跳躍；μ = 0 時 H、側力與槳轂力矩為零，且推力與扭矩等於軸向曲線；H 指向後方且低於動量理論上限；固定轉速下推力隨前飛速度增加（平移升力）、隨下降增加、隨爬升減少；左右旋鏡像；風車狀態的煞車力與葉片平板阻力同數量級；四顆槳的合力等於單顆負載之和；每步凍結係數與每階段重新查表的差異可忽略。

**適用範圍。** 旋翼前進比 μ 或 |λ| 超過 0.5（以槳尖速度計）時，葉片大部分失速或逆流，結果依賴平板模型，飛行報告會標出。渦環狀態只模擬平均誘導速度，推力脈動（propwash）沒有模擬。沒有非定常失速、旋轉失速延遲、雷諾數與馬赫數效應。

## 機臂遮擋

槳的下洗氣流打在機臂上會損失部分推力。目前以固定的淨推力比例表示（估計 0.95 ± 0.025）。

- 可信度：低。
- 實測方法：在推力台上比較有機臂遮擋與無遮擋的推力。

## 動力系統工作點（`powertrain.py`）

電源（電池或穩壓電源）是 Thevenin 源 V_s 串聯 R_s，航電是匯流排上的定功率負載。所有馬達使用相同 duty 時，匯流排電壓滿足：

    V_bus · (V_s − V_bus) / R_s = P(V_bus)

兩個根中較高的是穩定工作點。需求超過 V_s²/(4R_s) 時匯流排電壓崩潰，判定為不可行。

- **懸停**：已知所需推力，轉速、電流、電壓與 duty 都有閉式解。
- **全油門**：duty = 1，用 Brent 法在 [V_s/2, V_s] 中求解。

## 性能定義（`performance.py`）

- **懸停**：所有槳推力相同，淨推力（槳推力 × 遮擋係數）等於重量。
- **全油門**：滿電、靜止、短時間（極化壓降 v_rc = 0），只有 R0 造成壓降。
- **懸停續航**：從滿電開始穩定懸停，直到電量降到保留值，或負載下單芯電壓（在 ESC 端量測）降到下限，以先發生者為準。這是實際飛行的**上限值**。
- **懸停油門**：同時報告馬達輸出（ESC duty）與扣除 idle 後的搖桿位置，假設 duty 與 DShot 指令呈線性。

## 飛行動力學（`dynamics.py`）

第 5、6 階段的飛行模擬使用以下模型，固定步長 RK4，預設 8 kHz。

**剛體。** 位置與速度在世界 NED 座標，姿態為四元數，角速度在機體 FRD 座標：

    m v' = R F_body + m g ẑ + F_ground
    I w' = M − w × (I w + h_rotor),   h_rotor = Σ J_r ω_i s_i ẑ

h_rotor 是槳與轉子的自轉角動量，產生陀螺效應。

**馬達。** 每顆馬達以 motor.py 的平均模型求電流，轉子方程為 J_r ω' = Kt (I − I₀(ω)) − Q。機身受到的反作用扭矩是 −s_i·τ_motor，所以加速中的馬達也會產生偏航力矩。ESC 採互補式 PWM，電流可以反向（主動煞車並回充電池）。相電流兩側都有上限：

- 驅動上限代表 ESC 韌體的 ramp-up 與電流保護。沒有它，低轉速時突然全油門會吸收 V/R 的電流（數百安培），不符合實際。
- 煞車上限決定收油時馬達減速多快。

兩個上限都是估計值，應由轉速與電流遙測辨識。

**槳的力與力矩。** 有槳葉幾何的槳（預設）用斜向氣流模型（上一節）：每顆槳以槳轂相對空氣的速度（含機體角速度造成的部分）查表，得到推力（乘機臂遮擋比例）、槳盤阻力與側力、槳轂力矩與扭矩。查表在每個 RK4 步的第一階段做一次，其他三個階段沿用係數，但 q = ρ A V_ref² 仍隨轉速與空速逐階段更新。

沒有幾何的槳（只有實測係數表）用舊的軸向模型：Ct(J)、Cp(J) 以軸向入流計算（下降時沿用 J = 0），槳盤阻力用動量理論 F = −k_rd·ω·v_hub,inplane，k_rd = f_rd·√(ρ A kT / 2)，f_rd 是 `prop.rotor_drag_factor`（動量理論是上限，需要校正）。

**機身阻力。** 各機體軸分別為 F = −½ ρ |v| CdA_axis v_axis。機架的阻力作用在機架上的固定點（機架檔的 `drag_center`，估計為正面與上表面面積的形心），零件自己的阻力作用在零件位置，兩者都會依相對重心的位置產生力矩；所以加掛零件讓重心升高時，機架阻力的力臂也跟著改變。CdA 與 `drag_center` 是估計值，可用滑行減速、風洞或定速平飛的配平俯仰角辨識。

**地面接觸。** 機架定義的接觸點（機臂末端、底板、電池綁帶頂部）以彈簧阻尼模擬法向力，並加上正規化的庫侖摩擦。觸地垂直速度超過 3 m/s 判定為墜機。

**電池與匯流排。** 每次計算都把電池 Thevenin 源、四顆馬達的電流與航電的定功率負載一起求解匯流排電壓（一元二次方程的閉式解）；碰到 ESC 電流上限的馬達改以定功率負載重新求解。電池溫度是狀態之一：內阻跟著溫度變化，散熱依機體空速計算。

**陀螺儀（`sensors.py`）。** 量測值 = 真實角速度 + 白雜訊（雜訊密度 × √(fs/2)）+ 振動線。振動線鎖定每顆轉子的角度，諧波為 1 倍、2 倍與葉片數倍轉速，振幅 ∝ (ω/ω_ref)^p，三軸權重為 (1, 1, yaw_ratio)，相位為隨機（固定種子）。振動只進入量測，不影響剛體運動。振幅綜合了槳與馬達的不平衡和機架傳遞，是估計值，應由實機未濾波陀螺儀頻譜辨識。

**飛控。** 見 [flight-sim.md](flight-sim.md)。

可信度：剛體、馬達與電池方程為高到中；斜向氣流的槳力為中低（標準模型，但葉片幾何、失速模型與揮舞比例都是估計）；機身阻力、ESC 電流上限與振動為低（估計值）。沒有模擬的效應：propwash 推力脈動、機架彈性與共振、地面效應、風切與紊流（後三項見 [physics-roadmap.md](physics-roadmap.md)）。
