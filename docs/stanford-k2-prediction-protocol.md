## One bounded numerical experiment

Run only this case at 80 and then 120 points in each electrode/particle coordinate, with separator grids 40 and 60. Same source waveform, initial state, thermal boundary and tolerances on both meshes. Spatial gates stay maximum voltage difference ≤0.005 V, maximum temperature difference ≤0.1 K, cutoff-capacity relative difference ≤1%, correct voltage events and physical audits passing for both grids. Compare on the shared time domain with each true event endpoint recorded; do not remove real cutoff-tail differences.

Use existing free cloud CPU, one total worker wall budget of 1200 seconds and a hard 4,000,000,000-byte address-space limit. There are at most two new solves. Save the complete 80-point curves/report before attempting 120. An 80-point empirical disagreement alone does not cancel the numerical check. Stop on a physical-audit/solver error or budget exhaustion, preserving partial evidence; do not extend the budget, increase mesh again, relax tolerances or fit parameters. If the numerical check is missing or fails, predictive qualification stays unverified even if a coarse residual happens to satisfy an empirical threshold.
