# 電池：從量測到選型

電池決定續航、全油門能撐多久、冬天與老化後還能不能飛，也是全備重量裡最大的一項。這一頁把電池相關的工具串成一個流程；方程式在 [models.md](models.md#電池batterypy)。

| 步驟 | 工具 | 得到什麼 |
|---|---|---|
| 1. 量測 | 真實 HPPC 測試，或 `fpvsim hppc`（虛擬測試台） | 脈衝放電的電壓、電流、溫度 CSV |
| 2. 辨識 | `fpvsim fit-battery` | R0、R1、τ1、開路電壓曲線、活化能，附不確定度；可直接貼回零件檔 |
| 3. 設計評估 | `fpvsim report`（設計報告） | 懸停續航、全油門可持續時間、溫升，以及低溫、高海拔、老化電池等設計點 |
| 4. 選型 | `fpvsim battery-sweep` | 同系列不同容量的取捨與建議容量 |
| 5. 任務 | `fpvsim mission` | 實際飛法（重複綜合飛行）下的飛行時間 |

## 1–2. 量測與辨識

**HPPC（hybrid pulse power characterisation）。** 電池放在恆溫箱，每 10% 電量做一次：靜置（讀開路電壓）→ 5C 放電脈衝 30 s → 靜置 120 s（電壓恢復）→ 1C 放電到下一個電量。脈衝邊緣的瞬間壓降給 R0，脈衝中與恢復時的慢變化給 R1 與 τ1，靜置電壓給開路電壓曲線。

```bash
fpvsim hppc data/builds/ref-5in-6s-freestyle.toml --temperature 25degC --csv hppc_25C.csv   # 虛擬測試（已知參數加量測雜訊）
fpvsim fit-battery hppc_0C.csv hppc_25C.csv hppc_40C.csv --build data/builds/ref-5in-6s-freestyle.toml   # 兩個以上溫度時另外給活化能
fpvsim fit-battery --log flight_log.csv --build data/builds/ref-5in-6s-freestyle.toml   # 飛行 log：電池加導線的總電阻
```

- 每個脈衝以非線性最小平方法擬合 V = a − b·q − I·R0 − v_rc（v_rc 由 RC 方程以實測電流驅動），標準誤差由 Jacobian 估計。整包的值為各脈衝的平均，不確定度包含脈衝之間的差異（模型的定內阻假設在不同電量下不完全成立，這部分算進不確定度，而不是只用擬合的統計誤差）。
- 活化能由 ln R0 對 1/T 的迴歸求得，三點以上時取 HC3 誤差與各點誤差傳遞兩者中較大者。
- 飛行 log 的辨識只是飛行中的檢查：溫度與電量都在變，得到的是電池加上導線的電阻，不能取代測試台。
- 驗證：虛擬 HPPC 以已知參數產生數據，辨識回 R0、R1、τ1 的誤差在 0.2% 內，活化能 20.03 kJ/mol（設定 20）（`tests/test_battery_fit.py`）。

## 3. 設計評估

設計報告用電池的電路模型與熱模型計算懸停續航（保留電量、負載下單芯電壓或溫度上限先到者）與**全油門可持續時間**（取代標示 C 數的電流上限：溫度上限、瞬間電壓下限或保留電量先到者），規格可以列出多個**設計點**（例如冬天 0 °C、電池 5 °C；2000 m 高海拔；200 次循環的老化電池；最差組合），報告逐一評估。

## 4. 選型（`fpvsim battery-sweep`）

```bash
fpvsim battery-sweep data/builds/ref-5in-6s-freestyle.toml                       # 850–2200 mAh
fpvsim battery-sweep data/builds/ref-5in-6s-freestyle.toml --capacities 1050,1300,1550 --samples 1000
```

沒有品牌數據時，以設計檔自己的電池為基準，用同系列的縮放律描述其他容量（容量比 r = C/C₀）：

| 量 | 縮放 | 依據 |
|---|---|---|
| 容量 | × r | 定義；實際容量與標示的差異隨之縮放 |
| 質量 | m_o + (m₀ − m_o)·r | 電芯質量與容量成正比；m_o 是接頭、電源線、平衡線與外皮（`overhead_mass`，估計 18 ± 5 g） |
| R0、R1 | × r^(−n) | 極板面積與容量成正比時 n = 1（`resistance_exponent`，估計 1.0 ± 0.15） |
| 尺寸 | 每邊 × r^(1/3) | 體積與容量成正比，三軸等比例 |
| 對流散熱 hA | × r^(2/3) | 表面積 |
| 熱容量 | 隨質量 | 比熱 × 質量 |

兩個縮放參數放在電池零件檔的 `[family]` 表，附不確定度，和其他參數一起抽樣。電池靠機架的一面固定，較大的電池往上長，`mounted_on` 電池的零件（綁帶、相機座）跟著頂面移動，所以槳葉間隙（R7）與重心高度也跟著變。

每個容量用相同的蒙地卡羅樣本：每個樣本的縮放後數值由該樣本的基準電池參數與縮放參數算出，所以容量之間是成對比較，r = 1 時與設計報告完全相同（測試驗證）。報告列出各容量的推重比、續航、全油門持續時間、槳葉間隙與各規格的符合機率，並建議**符合全部規格機率最高**的容量（差距 2 個百分點內時取懸停續航較長者），也列出每多一克電池換到的懸停時間。

限制：真實電池系列的縮放未必這麼規則（不同容量可能用不同電芯，外形可能只改長度）。有兩種以上容量的實測質量與內阻時，質量對容量的截距就是 `overhead_mass`、內阻對容量的對數斜率就是 `resistance_exponent`。

## 5. 任務續航（`fpvsim mission`）

```bash
fpvsim mission data/builds/ref-5in-6s-freestyle.toml --fc data/fc/acro-5in-baseline.toml              # 重複 freestyle 腳本
fpvsim mission data/builds/ref-5in-6s-freestyle.toml --fc data/fc/acro-5in-baseline.toml --wind 6       # 有風
```

懸停續航是功率的下限、時間的上限；freestyle 是重度使用。任務續航以 6DOF 模擬從滿電、靜置的電池開始，一圈接一圈重複同一段飛行腳本，直到：

- 保留電量；
- 單芯電壓的 **1 秒平均值** 達到下限（相當於 OSD 低電壓警告；衝刺時的瞬間壓降不算）；
- 電池溫度上限；墜機；或圈數上限。

測試飛手每圈開始時依電池目前的狀態重新估計懸停油門，就像真人飛手會隨電壓下降加油門。為了縮短計算時間，物理以 4 kHz 計算（陀螺儀與 PID 迴圈也是 4 kHz），記錄 50 Hz；幾分鐘的飛行大約要算幾分鐘。

報告列出任務時間與懸停續航的比值、用電量、平均功率、各圈的耗電與最低電壓、溫升，並檢查電荷守恆（記錄的 ∫I dt 與電池模型的電量變化相符）。

限制：沒有馬達溫升，長時間大電流時結果偏樂觀；每圈衝刺後高度累積增加，模型的空氣密度固定在規格高度（無風時不影響結果）；測試飛手不代表真人的飛行風格。
