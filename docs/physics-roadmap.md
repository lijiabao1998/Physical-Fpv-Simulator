# 物理模擬規劃

這份文件規劃模擬器的物理模型要怎麼一步一步變得更真實。原則和整個專案相同：

- **每個模型都要寫清楚四件事**：方程與出處（公開文獻）、參數與不確定度、驗證方式（程式有沒有正確解方程，用解析解或極限情況測試）、確認方式（方程符不符合現實，需要什麼實測數據）。
- **先做影響結論的模型。** 一個效應值得模擬，是因為它會改變設計決定（選哪顆電池、相機裝哪裡、增益調多少），而不是因為它看起來比較真實。
- **適用範圍要監測。** 模型在哪裡失效，就在報告裡標出來，而不是悄悄外插。

## 2. 規劃

分成四層，前一層的結果是後一層的輸入。「本輪」是這次實作的項目。

### 第 1 層：電池與電氣（本輪）

| 項目 | 模型 | 驗證 | 確認需要的數據 |
|---|---|---|---|
| 溫升 | 集總熱模型 C_th dT/dt = I²R0 + v_rc²/R1 − hA(v)(T − T_環境)；hA 隨氣流速度增加（層流強制對流 ∝ √v） | 定電流下的解析解（指數趨近穩態溫度） | 放電時貼熱電偶量電池表面溫度 |
| 內阻隨溫度 | Arrhenius：R(T) = R_ref exp[(Eₐ/R)(1/T − 1/T_ref)] | T = T_ref 時等於原值；Eₐ 由兩個溫度的內阻反推 | 不同溫度下的 HPPC 脈衝測試 |
| 老化 | 容量與內阻隨循環次數線性變化（一階近似） | 0 次循環等於新電池 | 定期記錄充電器的內阻與實際放電容量 |
| 用物理限制取代標示 C 數 | 全油門可持續時間：電芯溫度、瞬間電壓或保留電量先到者 | 與熱模型、Thevenin 模型的閉式估算比較 | 全油門衝刺時的電壓、電流與溫度 log |
| 最差工況設計點 | 規格檔列出多個工況（低溫、高海拔、老化電池），報告逐一評估規格 | 標準工況的結果與原報告相同 | — |
| 參數辨識 | `fpvsim fit-battery`：HPPC 脈衝測試或 Blackbox log → R0、R1、τ1、開路電壓曲線，附不確定度 | 用已知參數產生的虛擬測試數據，辨識結果要落在不確定度內 | 實際的 HPPC 測試或飛行 log |
| 電池選型 | 參數化電池族（質量、內阻、尺寸隨容量縮放），掃描容量 | 掃描點等於原電池時結果相同 | 幾顆不同容量電池的秤重與內阻 |
| 任務續航 | 6DOF 重複飛綜合飛行腳本直到保留電量或低電壓 | 能量守恆：用電量 = ∫I dt | 實機計時與 Blackbox 用電量 |

### 第 2 層：槳在斜向氣流中的空氣動力（本輪）

目前的槳盤阻力是動量理論的上限乘上 0.5，這個 0.5 是讓前飛速度看起來合理才選的。改成從葉片幾何算出來：

- **前飛 BEMT。** 葉片元素沿半徑與方位角積分：切向速度 Ωr + V_e sin ψ，垂直速度 V_c + v_i(r, ψ)。得到推力 T、面內力 H（真正的槳盤阻力）、扭矩 Q，以及前進側與後退側不對稱造成的槳轂滾轉力矩和俯仰力矩。
- **誘導速度。** Glauert 動量理論 T = 2ρA v_i √(V_e² + (V_c + v_i)²)；縱向入流梯度用 Drees 線性入流模型。
- **渦環狀態。** 軸向下降時動量理論失效，改用文獻的經驗誘導速度曲線（Leishman《Principles of Helicopter Aerodynamics》第 2 章）。水平速度夠大時逐漸回到 Glauert 解，因為尾流被吹離槳盤。
- **錨定在軸向數據。** 前飛模型給出相對於軸向的比例；軸向本身仍用實測或 BEMT 的 Ct(J)、Cp(J)。有推力台數據時，前飛結果也跟著它校正。
- **查表。** 每顆槳預先算出以前進比 μ = V_e/(ΩR) 與入流比 λ_c = V_c/(ΩR) 為座標的無因次係數表，飛行時雙線性內插。

驗證：μ = 0 時等於軸向 BEMT；小前進比時 H 力與動量理論同數量級；推力隨前進比先增加（平移升力）是旋翼的已知行為。確認：風洞中槳在不同風速與攻角下的推力、H 力與扭矩（見第 4 層）。

## 3. 虛擬風洞

真實研發會把整機或單顆動力組放進風洞，用天平量測力與力矩。虛擬風洞做同樣的事，但對象是模型：

- **用途一：看懂模型。** 前飛時要多大的傾角、多少功率，槳盤阻力和機身阻力各占多少，俯仰力矩要飛控出多少力。
- **用途二：設計量測。** 先在虛擬風洞決定要量哪些風速與攻角，真實測試才不會漏掉重要的點。
- **用途三：辨識參數。** 把真實風洞（或滑行、定速平飛）的量測數據套回模型，辨識機身阻力面積、阻力中心和槳的面內力倍數，附上不確定度。

### 試驗段與天平

- 機體固定在天平上，天平量測點預設在重心；來流速度 V、攻角 α（機頭向下為正，對應前飛時的前傾）與側滑角 β。
- 量測六分量：升力、阻力、側力（風軸），滾轉、俯仰、偏航力矩（機體軸，對量測點）。
- 槳的三種狀態：停轉（量機身阻力）、固定轉速、固定油門（馬達、ESC 與電池一起求平衡轉速）。

### 試驗項目

1. **機身阻力極曲線**：槳停轉，掃描風速與攻角。
2. **動力組斜向氣流**：單顆槳在固定轉速下，掃描前進比與攻角，得到推力、H 力、扭矩與功率。
3. **配平曲線**：每個風速下，求出水平定速飛行需要的傾角與油門（升力 = 重量、阻力 = 推力的水平分量），以及配平後還剩多少俯仰力矩要由飛控提供。
4. **功率曲線與最佳巡航速度**：配平功率對速度，找出續航最久與航程最遠的速度，以及全油門能達到的最高平飛速度。

### 用真實風洞數據辨識

`fpvsim fit-tunnel` 讀取天平量測的 CSV，以最小平方法辨識 CdA、阻力中心與面內力倍數，誤差用 HC3 穩健標準誤差，輸出可以直接貼回零件檔的數值。虛擬風洞也能加上量測雜訊產生合成數據，用來驗證辨識流程，就像虛擬推力台和 `fit-prop` 的關係。

真實風洞要做的修正（洞壁阻塞、尾流阻塞、天平干擾）屬於量測端，應在匯入數據前完成；虛擬風洞是自由流，沒有這些效應。

## 4. 驗證計畫

每個新模型都有對應的測試（`tests/`）：

| 模型 | 測試 |
|---|---|
| 熱模型 | 定電流、定 hA 時與解析解相符；沒有電流時趨近環境溫度 |
| Arrhenius | T_ref 不變；0 °C 與 25 °C 的比值等於設定的活化能 |
| 老化 | 循環次數 0 等於新電池；容量與內阻變化方向正確 |
| fit-battery | 虛擬 HPPC 數據（已知參數加雜訊）辨識結果在 2σ 內 |
| 前飛 BEMT | μ = 0 等於軸向 BEMT；H 力為正（指向後方）；左右旋的滾轉力矩反號 |
| 渦環狀態 | 經驗曲線在 V_c/v_h = 0 與 −2 兩端與動量理論銜接 |
| 紊流 | 產生的序列標準差與功率譜符合 Dryden 公式 |
| 地面效應 | 遠離地面時比值趨近 1 |
| 風洞 | 槳停轉時阻力等於 ½ρV²CdA；配平時力平衡 |
| fit-tunnel | 合成數據辨識回原值 |
