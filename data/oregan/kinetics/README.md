# Original O'Regan parameter measurements

These nine CSVs are unchanged members of the version 1.0 archive by Kieran O'Regan, Ferran Brosa-Planella, W. Dhammika Widanage and Emma Kendrick, DOI [10.5281/zenodo.5171874](https://zenodo.org/records/5171874), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The [manifest](../../oregan-kinetics-manifest.json) records original member names, lengths, SHA256 digests, archive MD5/SHA256, official download URL and API-verified attribution/license. Only nine small members are included, totalling 2,031 bytes; the original archive is 479,705 bytes. CSV content has not been edited. Analytical comparisons and support annotations are separate derived outputs.

Exchange-current density is mA/cm² in the source; multiply by 10 to obtain A/m². Stoichiometry is an electrode quantity, not full-cell state of charge. Temperature in exchange-current filenames is °C. Electronic-conductivity CSV temperatures use rounded kelvin labels. See [the provenance audit](../../../docs/oregan-kinetics-provenance.md) for interpretation limits. No laboratory endorsement is implied, and these data's license does not license original repository code.
